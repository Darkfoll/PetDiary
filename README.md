 PetDiary — приложение для дневника питомца
 О проекте
PetDiary — это Android-приложение, в котором можно:

создать профиль питомца (имя, порода, возраст, фото),

вести дневник по дням с текстом и фотографиями,

пройти регистрацию / авторизацию перед входом,

переключать фоновые картинки при старте.

Проект написан на Kotlin с использованием стандартных компонентов Android + кастомная календарная элемент интерфейса WeekCalendarView.

Уровень сложности кода: от начального до среднего. Ты поймёшь всё без проблем.

 Общая архитектура
text

 Как работает календарь (важно)
В DiaryActivity используется библиотека:

kotlin
com.kizitonwose.calendar.view.WeekCalendarView
Отображается одна неделя.

Сверху два спиннера: месяц + год.

При клике на день:

меняется визуально (кружок)

обновляются записи внизу

Записи хранятся в allEntries и фильтруются по selectedDate

 Фото в дневнике
Выбор фото через ActivityResultContracts.GetContent()

Uri сохраняется в DiaryEntry.imageUri

В DiaryAdapter показывается через setImageURI

 Uri может потеряться после перезапуска приложения (не сохранён на диск).
Это нормально для текущей версии.

 Создание питомца
Нижнее окно HabbBottomSheet

Карточка добавляется динамически в cardsContainer

При нажатии на карточку → DiaryActivity

 Регистрация / вход
Только один пользователь (данные перезаписываются)

Email + пароль (пароль минимум 4 символа)
